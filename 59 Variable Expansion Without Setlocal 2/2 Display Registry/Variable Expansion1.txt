VARIABLE EXPANSION WITHOUT SETLOCAL :

EXAMPLE SCRIPT :
-------------------------------------------------------------------------------------------------------
Example 1

@echo off

reg query "HKLM\Software\Microsoft\Command Processor" /v "DelayedExpansion"
--------------------------------------------------------------------------------------------------------

---------------------------------------------------------------------------------------------------------
Example 2

@echo off

for /f %%g in ('reg query "HKLM\Software\Microsoft\Command Processor" /v "DelayedExpansion"') do (
	echo %%g
)
-----------------------------------------------------------------------------------------------------------

---------------------------------------------------------------------------------------------------------
